# BoB
Le jeu « Burnout or Billionaire » est un jeu de gestion/survie psychologique en HTML/CSS/JavaScript où le joueur doit équilibrer :  l’argent 💰, l’énergie ⚡, la santé mentale 🧠,  tout en essayant d’éviter le burnout.  Le principe repose sur une boucle de vie quotidienne simulée heure par heure.
